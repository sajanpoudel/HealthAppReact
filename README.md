# HealthAppReact

A React front end for a personal health dashboard. Patients can see their
analysis and hospital reports, and doctors can upload a patient report as a PDF
with their comments.

## Pages

| Route | Page |
| --- | --- |
| `/` | Landing page |
| `/login` | Log in and sign up (a placeholder, any input signs you in) |
| `/dashboard` | Personal analysis |
| `/hospital-reports` | Reports history with a PDF viewer |
| `/upload` | Form to upload a patient report |

## Run

```
npm install
npm start
```

Node 18 is expected (see `engines` in `package.json`).
